# Waterproofing (fictional company, portfolio project)

Read BRIEF.md first. Use the approved stack documented there (Astro, static output, GSAP, Cloudflare Pages).

## Rules
- Commit each completed, verified step with a clear message. Test before committing.
- Never push or force-push. Get approval before any production change or deploy.
- Never commit .env files or secrets. Keep `.env*` in .gitignore (only `.env.example` templates allowed) before the first commit.
- Never expose secrets in code, logs, browser bundles, or chat.
- Use emil-design-eng for animations and interactions; use Impeccable for design and UI audits.
- Real photography only (no illustrations, AI-generated, or cartoon images). Check stock licenses.
- Never invent testimonials, certifications, numbers, or claims. Label placeholder content "sample".
- Support iOS Safari and Android Chrome plus modern browsers; respect prefers-reduced-motion.
- No database, SQL, checkout, or payments. Contact is a WhatsApp button with a prefilled message, plus social links.
- Copy is pt-BR.
